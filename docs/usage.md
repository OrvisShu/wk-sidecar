# 功能与使用

## 快速记录

在「待处理」页的输入框写下任务，选择「1 小时」「3 小时」「明天」或自定义提醒时间，然后按回车或加号。自定义时间必须在未来，最长可设置到一年后。待办按提醒时间排序，最紧急的任务会显示在窗口上方。

## 提醒与怪物

怪物阶段由任务的提醒时间计算，不依赖应用一直开着：

| 时间 | 阶段 |
| --- | --- |
| 提醒时间之前 | 待办萌芽 |
| 到期 | 小怪出现 |
| 逾期 1 小时 | 怪物成长 |
| 逾期 6 小时 | 怪物暴走 |
| 逾期 24 小时 | 大 Boss |

到期后约每小时发一次系统通知，多个任务同时到期时会合并提醒。任务旁的闹钟按钮可将**下一次通知**延后 30 分钟；它不会改变原提醒时间或进化阶段。关闭桌面提醒后，任务仍照常进化。

通知依赖程序运行。点击窗口关闭按钮只是隐藏到托盘，通知会继续；从托盘选择「退出」后不会继续提醒。再次启动时会按当前时间重新计算阶段。

## 完成与经验

点击任务前面的圆形按钮即可完成，获得 20 XP，并显示鼓励语。提示中的「撤销」可立即恢复任务。已完成任务留在「已完成」页；删除已完成任务会相应扣除其经验。英语复习也会增加同一份总经验，待办与英语页共用等级进度。下一等级所需经验会逐级增加。

## 窗口与偏好

拖动标题栏可移动窗口。图钉按钮切换置顶，向下箭头收起窗口，收起后可用向上箭头展开；关闭按钮隐藏到系统托盘。托盘双击图标重新打开，右键可退出。重复启动程序只会唤回已有窗口。

开启「贴边自动隐藏」时，把窗口拖到屏幕左侧或右侧，松开后会吸附；鼠标移出窗口后会收成边缘把手，悬停把手即可展开。设置中的「贴边位置」也能直接选择左侧、右侧或不贴边。拖动展开的窗口离开屏幕边缘可取消贴边。贴边位置会在重启后恢复；使用「隐藏到托盘」会连把手一起隐藏，从托盘打开会再次展开。

设置中可切换桌面提醒、窗口置顶、开机启动、跟随系统/深色/浅色主题和 65% 至 100% 的透明度。开机启动由 Windows 或 macOS 系统管理。任务、经验、窗口位置和偏好会在重启后恢复。

设置中的「导出」可保存 JSON 文件；「导入」会替换当前任务、英语卡片和经验，保留当前设备的窗口位置与偏好。详见[数据与恢复](data.md)。

「英语」页支持速记单词、短语和句子，以及到期复习。具体流程和提醒规则见[英语速记与复习](english.md)。导入时英语卡片也会一起替换。
