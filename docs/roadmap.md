# 迭代方向

当前版本适合个人本机使用。以下是后续工作清单，不代表已经支持或有固定发布时间。

## 优先处理

1. 编辑任务标题和提醒时间，避免只能删除后重建。
2. 增加安静时段与提醒频率设置，避免工作外时间或大量任务产生打扰。
3. 为通知、导入导出和开机启动增加更完整的桌面端回归测试。
4. 为 Windows 安装程序增加代码签名和自动更新；当前未签名版本可能触发 SmartScreen 提示。
5. 为英语复习增加可配置的安静时段、每日上限和更多键盘操作。

## 后续评估

- 重复任务、任务归档、搜索与筛选。
- 数据文件版本号和显式迁移机制；跨设备同步前先明确冲突规则。
- 更完整的键盘操作和无障碍检查。
- 多平台打包、发布流程与更新机制。

每项功能落地时应同时更新[使用说明](usage.md)、[数据说明](data.md)及对应测试，并检查悬浮窗口在小屏和高 DPI 下的布局。
