# 英语速记与复习

## 记录

默认按 `Ctrl + Shift + E` 打开速记窗，也可以在主窗口的「英语」页点击「速记」。输入英文内容即可保存单词、短语或句子；中文释义和语境可以稍后补充。未填释义的卡片显示为「待补释义」，不会进入复习队列。主窗口支持搜索、编辑和删除卡片。

速记、编辑和复习小窗可拖动顶部标题栏移动，按 `Esc` 或点击右上角关闭。关闭后窗口会隐藏，再次打开时复用同一窗口；未保存的速记内容会清空。Electron 的主进程、渲染进程和辅助进程仍会分别显示在任务管理器中，但重复启动程序只会唤回现有应用实例。

快捷键可以在设置中切换为 `Ctrl + Alt + E` 或 `Alt + Shift + E`。若被其他程序占用，设置会提示失败并保留先前的组合。速记窗不读取当前选择的文本或剪贴板，需要用户自行输入或粘贴。

## 复习

「英语」页显示到期数量，点击「复习」打开小窗。先回想英文的意思，再点「显示释义」，选择「忘记」「困难」「记得」「很容易」。调度使用 `ts-fsrs` 的 FSRS 算法；每次评分会更新下次复习时间。新卡片可立即手动复习。

每张卡片每天首次完成复习可获得 5 XP，四种评分都计入；同一天重复复习仍会更新记忆间隔，但不重复加经验。英语复习与完成待办共用首页的总经验和等级。删除卡片会扣回该卡片累计获得的经验，与删除已完成待办的规则一致。

自动复习提示只使用系统通知，不会主动抢焦点。提示在本地时间 09:00 至 22:00 之间出现；卡片创建至少 30 分钟后才会提示，通知间隔至少 3 小时，每天最多 3 次。点击通知才会打开复习窗。可在设置中关闭英语复习提醒，手动复习仍可使用。程序完全退出时不会通知，再次启动后会重新检查到期卡片。

## 数据

英语卡片、FSRS 调度状态、累计经验和最近的评分历史与待办一起保存在 `tasks.json` 中，随应用备份和导出。每张卡片最多保存最近 100 条评分记录，较早的评分被裁剪也不会丢失累计经验。导入 JSON 时会替换任务、卡片和经验，保留当前设备的窗口位置与偏好。详见[数据与恢复](data.md)。
