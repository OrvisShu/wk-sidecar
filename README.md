# 打怪待办

常驻桌面的悬浮待办助手。快速记下任务，设置提醒时间；任务到期后会从小怪逐渐进化为 Boss。完成任务可获得经验，并在「已完成」中查看记录。

## 运行

```bash
npm install
npm start
```

需要 Node.js 22.12 或更高版本。运行后可拖动顶部栏移动窗口，点击向下箭头收起，点击关闭按钮隐藏到系统托盘；在托盘双击图标可重新打开，右键选择「退出」才会结束程序。

在 Windows x64 上运行 `npm run package` 可生成独立可执行版：`release/打怪待办-win32-x64/打怪待办.exe`。整个目录需要一起保留；它与开发版使用同一份用户数据。这是便携版目录，目前没有安装器或自动更新。
